Features

Everything you need to design a gem

◈

7 Classic Cut Styles

Generate Brilliant, Emerald, Marquise, Oval, Pear, Cushion, and Princess cuts. Each is built from precise mathematical outlines — not approximations.

⊛

Full Parametric Control

Adjust diameter, total depth, table size, crown height, pavilion depth, facet counts, girdle thickness, and culet size — every proportion of the gem is yours to control.

⇅

Mirror Crown

Flip the crown to the bottom and create a perfectly symmetrical bicone — ideal for pendants, beads, and decorative stones that look the same from both sides.

◻

Crown Only (Cabochon)

Generate just the crown with a flat base — perfect for inlay work, flat-backed pendants, and prints that need to sit flush against a surface.

⇓

Binary STL Export

Download a compact binary STL ready for any slicer — PrusaSlicer, Cura, Bambu Studio, or online tools like viewstl.com. Dimensions are in real millimetres.

◑

Live 3D Preview

A three.js WebGL preview updates in real time as you drag sliders. Orbit, zoom, toggle wireframe, and switch between dark and light mode.

☁

Works Offline

All geometry is computed client-side in your browser — no server, no upload, no account needed. Open the file directly or host on GitHub Pages.

⊕

Sharp Girdle Edge

Set girdle thickness to zero for a sharp-edged gem where the crown and pavilion meet at a single ring — great for faceted bead shapes.
